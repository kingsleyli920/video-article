# 补充验收：英语视频为主（xvc-additional-test-cases.json）

清单 `xvc-additional-test-cases.json`（schema 1.1，2026-11-25）是一份补充验收案例池：15 个真实英语视频、12 个人工构造的语义案例、3 个受控管线案例，执行前状态都是"未执行"。这份记录说明去重结果、预检结果、实际执行了哪些、证据在哪、还剩哪些缺口。

## 结论

- **发现并修复了 2 个产品缺陷**：
  - 选字幕轨：英语视频会选到阿拉伯语字幕，或者误报没有字幕（预检发现）；
  - 字数上限：术语和数字多的文章会超出上限（V08）。
- **另外修了 2 处数字和度量问题**：多组千分位跨字幕没有拼回（C02）；短文和"小标题下一行紧跟正文"的写法，首个可读段落记成 null。
- **修复后的情况**：
  - 第一批 8 个真实视频、9 个语义案例全部合格；
  - 字数修复后回归 7 次，都没有超过上限；
  - 修复已部署到线上（`2b99ac9b`），线上默认模型没有切换。
- **没有完成的**：线上验证只完成了一半，Gemini 预付余额在这时用完，之后的请求都返回 HTTP 402。详见"线上验证"一节。

## 范围和环境

- **配置**：第八轮推荐的候选配置，`gemini-4-hydrogen` + `high`，备用模型 `gemini-3.6-flash`。线上默认模型没有切换，所以真实模型案例都在本地 `wrangler dev` 上跑，用 `--var` 覆盖模型和思考档。没有做"视频 × 模型 × 思考档"的组合。
- **真实视频**：本地 Worker（8787）直连 YouTube，用的是生产的字幕模块。出口是本机网络，不是 Cloudflare；线上能否取到这些视频的字幕没有验证。
- **语义案例**：另一个本地 Worker（8797）用 `YOUTUBE_PLAYER_URL` 指向本地字幕替身（`test/harness/serve-semantic-fixtures.ts`），字幕来自 `test/fixtures/additional-semantic.json`，按 YouTube 的方式两层转义；预处理、提示词、Gemini、保存和 5W1H 接口都是生产代码。清单没给元数据的案例用中性标题"测试视频 Rxx"，不把考点写进标题。
- **受控管线案例**：不调用模型，写成 L1a / L1b 自动化测试。
- **代码版本**：预检和选轨修复在 `f7920fd`。第一批真实模型运行在 `f7920fd` 加上未提交的计时修正上（只改了首个可读段落的计算，不影响生成），之后提交为 `a02c705`；字数修复后的回归在 `a02c705` 上、两个 Worker 干净重启后进行。

| # | 问题 | 怎么发现的 | 处理 |

| 2 | Royal Institution 讲座（V14）误报没有字幕 | 预检 | 同上 |
| 3 | ",345,678" 这类多组千分位被拆到下一条字幕时没有拼回，输出 "12 ,345,678" | C02 | 修复（`f7920fd`） |
| 4 | V08 要求"最多 1500 字"，按统一口径写了 1,695 字 | 内容核对 | 提示词改为按上限八成分配篇幅（`a02c705`），回归通过 |
| 5 | 首个可读段落记为 null：只有一段正文的短文（R04、R09），以及每块都是"### 小标题\n正文"的文章（R10） | 结果核对 | 修复（`a02c705`、`f6d5b87`），只影响计时，不影响生成 |

**选轨的原因**：原来的规则排除地址带 `variant` 的轨道，靠"不带变体参数的自动识别轨"判断原声语言。但这些视频的原声英语自动识别轨带 `variant=gemini`（示例视频里，其他语言的配音轨带的是 `variant=timing-optimized`），排除之后判断不出原声，只能退回"第一条人工字幕"，按排序就是阿拉伯语。V14 只有这一条轨道，于是报无字幕。

**选轨的修复**：原声语言依次看默认音轨的编号（`en-US.4`）、不带变体参数的自动识别轨、默认音轨的默认字幕轨，再在同语言里按人工字幕、自动识别、带变体参数的自动识别选。修复后 17 个视频都选中了英语轨；示例视频和乔布斯演讲选中的轨道不变，整理后的文本逐字相同（107,416 和 12,202 字符）。

**我自己的操作问题**（不算产品缺陷，原始输出保留在 `evidence/additional/invalid-runs/`）：

- 第一批运行中途我改了 `src/`，本地 `wrangler dev` 热重载，进行中的 5 个探针和 1 个浏览器用例全部在模型输出前中断。之后运行期间不再改 `src/`，这几项全部重跑。
- V12 第一次浏览器运行的生成和保存都完成了，但用例里"首个正文要比模型结束早 5 秒"的断言不适用于高档思考下的短文（正文约 3 秒发完），停在了 5W1H 之前。断言改为"正文分块在至少 3 个不同时刻到达、首个分块早于模型结束"，然后重跑。
