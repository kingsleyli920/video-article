# 需求验收对照

逐条对应原题。每条写明验收标准、现状和证据。状态分三种：

- **通过**：已实现，当前线上版本有证据；
- **有缺陷**：已实现，但有已确认、还没关闭的问题；
- **缺验证**：已实现，当前版本没有直接证据。

测试通过不等于内容通过，历史版本通过不等于当前版本通过。当前线上版本 `3e5637a3`，由 `e310d0c` 部署；之后的提交只改文档和测试。逐条对照里标注 `d1de7b0d` 的证据来自上一个线上版本，独立审查之后改动的部分（核对、约束提取、提示规则）在 `3e5637a3` 上的复验见 [最终验收记录](FINAL_ACCEPTANCE.md) 第零节。证据目录 `evidence/` 在本机（未入库，审查包里有脱敏副本）；`docs/evidence/` 在仓库里。

| 17 | 浏览器验收的"正文持续增长"判断不可靠：量的是整个文章区域，完成时多出的核对记录也算进长度，"初稿一次贴出、随后多出核对记录"会被判通过 | 采样没有区分正文和核对记录，也没有限定在初稿生成阶段 | 只量正文，只看进入修订或核对之前有没有中间长度（`test/e2e/live/body-growth.ts`） | 反例在修复前被判通过、修复后判不通过；已有线上证据重算：进入核对前 264 条中间长度采样，仍通过（`evidence/final4/body-growth-recompute.json`） |

以上修复都没有针对具体视频、年份、人名或句子写特例。

## 字幕恢复

都从 Cloudflare 出口实测，用的是临时探针 Worker（测完已删除），后两轮直接调用生产代码。原始记录在 `evidence/recovery/`。

| 轮次 | 做法 | 结果 |
|---|---|---|
| 一 | 同一次请求里依次用几种客户端，42 轮 | ANDROID 新版 39/42、IOS 37/42、ANDROID 旧版 38/42，失败都是 HTTP 403；三者同时失败 0 次。TVHTML5、ANDROID_VR、WEB_EMBEDDED、MWEB 不可用 |
| 二 | 生产的 `fetchTranscript`（换客户端重试），120 次 | 95 次成功；25 次是人机验证拦截，三种客户端全部失败 |
| 四 | 直连被拦时比较三条出路，174 轮 | 直连被人机验证拦 23 次。同出口重试 0/23，换请求域名 0/23；同一时刻北美西部、北美东部、亚太的 Durable Object 各 23/23 成功；欧洲西部 0/174 |
| 五 | 生产的 `loadTranscript`（换客户端 + 换区域），320 次 | 320 次全部取到字幕：241 次直接成功，79 次是本地三种客户端都被拦之后由北美东部节点取到 |

- 线上真实生成里也有记录：V14、V02 那两次是本地三次被拦、换区域取到后继续生成并保存。
- 没有做到的：320 次全部成功是这一轮的样本，不是对以后的保证；本轮没有遇到北美东部也被拦、要用到第二个区域的情况；区域靠 `locationHint` 指定，探针里读到四个区域的对象分别落在丹佛、迈阿密、巴黎、新加坡，但 Cloudflare 不保证以后一定落在同一处。
- 题目建议的 webshare 代理没有采用：它需要额外的账号，而换区域在实测里已经救回了全部被拦的请求。

## 没有验证或没有做到的

- **Gemini 免费层**：题目写的是"免费 API"。线上 key 所在项目是付费档（预付费，没有开自动续充），余额用完时生成会失败并明确提示。`gemini-4-hydrogen` 有免费层，但免费层下高档思考的速度和限额没有复测。
- **已确认、没有关闭的内容问题**：当前版本线上那篇 V15 里，"seems to store""may be better served""probably not…seems"三处不确定语气被写成了确定说法，`COUNT(*)` 的括号没有口述依据。同一类问题在离线复验里各被查出过一部分，这一次漏了。它们不改变结论的方向，但按本项目自己的规则算问题。
- **核对的检出率不是 100%**：核对本身是模型做的，同一类问题在不同次运行里有时查出、有时漏掉。程序把关保证的是"改动有字幕依据、不改坏结构"，不保证"所有错误都被找到"。已知的漏检写在"内容验收"里。
- **等待时间**：第一段正文要等 20 到 90 秒，核对再加 20 到 80 秒，整篇 1 到 3.5 分钟。
- **备用模型**：线上从没真实触发过，只在受控故障测试里验证。
- **模型还没输出时点停止**：服务端要等下一次写入失败才发现，不保证立即取消上游。
- **Workers 免费版的 CPU 限制**：生成请求的 CPU 时间超过文档写的 10 毫秒，目前请求没有因此中断，也没有升级套餐。
- **超过 30 万字符的真实视频**：只有自动化测试覆盖。
